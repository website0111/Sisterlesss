Sisterless Engine (Social-Media-Anwendung)

„Sisterless Engine“ ist eine Anwendung, die die Band ausschließlich für ihre eigenen Konten verwendet. Sie schneidet Konzertvideos der Band zu kurzen Clips und veröffentlicht sie nach Freigabe durch die Bandmitglieder auf den Kanälen der Band (u. a. YouTube, Facebook, Instagram, TikTok).

  • Welche Daten? Die Anwendung nutzt die YouTube API Services von Google. Sie erhält Zugriff auf den YouTube-Kanal der Band, um Videos hochzuladen, den Status der hochgeladenen Videos abzufragen und Aufruf-Statistiken der eigenen Videos auszuwerten. Daten anderer YouTube-Nutzer werden nicht abgerufen oder gespeichert.
  • Wo werden sie gespeichert? Die Zugangsschlüssel und Statistiken liegen ausschließlich lokal auf dem Rechner der Band. Sie werden nicht an Dritte weitergegeben und nicht verkauft.
  • Wie lange? Solange die Band die Anwendung nutzt. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden; die lokal gespeicherten Daten werden dann gelöscht.

Durch die Nutzung der YouTube API Services gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“).
