Die Datei gehört in denselben Ordner wie index.html, also dorthin, wo auch merch.html und gigs.html liegen. Sobald sie dort hochgeladen ist, ist sie unter sisterless.band/datenschutz.html erreichbar.

Wie das Hochladen genau geht, hängt davon ab, wie dein Sohn die Website betreibt. Er weiß das sicher sofort. Die häufigsten Fälle:

  • GitHub (eventuell mit GitHub Pages oder Netlify dahinter): das Repository der Website öffnen → Add file → Upload files → datenschutz.html hineinziehen → Commit changes. Ein bis zwei Minuten später ist sie online.
  • Netlify per Drag & Drop: die Datei in den lokalen Website-Ordner legen und den ganzen Ordner wieder bei Netlify unter „Deploys“ hineinziehen.
  • Hosting mit FTP (z. B. World4You, all-inkl, IONOS): mit dem FTP-Programm verbinden, in den Ordner mit index.html wechseln (oft heißt er public_html, htdocs oder www) und die Datei hineinziehen.

Am einfachsten schickst du ihm die Datei datenschutz.html zusammen mit diesem Satz:

„Bitte neben die index.html legen und hochladen, dann ist sie unter sisterless.band/datenschutz.html erreichbar. Wenn du magst, im Footer neben ‚Impressum' einen Link ‚Datenschutz' auf datenschutz.html setzen.“

Bis er das erledigt hat, kannst du bei Google trotzdem schon alles eintragen und die App veröffentlichen, so wie in Schritt 5f beschrieben. Wie weit bist du dort gekommen?
